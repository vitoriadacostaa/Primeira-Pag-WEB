# 🌐 Minha Primeira Página Web

Este repositório marca o início da minha jornada como Programadora. É o meu primeiro projeto prático explorando as fundações da web, desenvolvido durante o meu curso Minha Primeira Página WEB - PrograMaria.

---

## 📝 Sobre o Projeto
O objetivo deste projeto foi aplicar os conceitos iniciais de estrutura e estilização web. Através dele, pude colocar em prática:
- Estruturação de documentos com **HTML5**.
- Estilização básica e posicionamento de elementos com **CSS3**.
- Boas práticas de organização de pastas e semântica.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estrutura e conteúdo.
- **CSS3**: Layout, cores e fontes.
- **Git & GitHub**: Versionamento e hospedagem.

## 🚀 O que eu aprendi
Neste projeto, foquei em entender como os elementos se comportam no navegador. Alguns dos desafios superados foram:
1.  Uso de tags semânticas (como `header`, `main`, `footer`) para melhor acessibilidade.
2.  Importação de fontes externas.
3.  Criação de um layout limpo e funcional.
